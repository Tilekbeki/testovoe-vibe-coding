# ANOMALIES.md

Проверка выполнялась командой:

```bash
npm run data:analyze
```

## Что найдено

1. В исходных JSON-страницах 1000 строк, но только 994 уникальных `id`.
   Повторяются `c_000285`, `c_000263`, `c_000367`, `c_000453`, `c_000254`, `c_000224`.

2. `review.csv` выглядит не как свежая выгрузка той же базы, а как смешанная/ошибочная поставка.
   В файле 205 строк, но только 6 строк имеют `id`, которые уже есть в `page_001.json` ... `page_020.json`.
   Остальные 199 строк имеют новые id вида `c_001005`, `c_001014`, `c_001119` и так далее, хотя исходная база заканчивается около `c_001000`.

3. В `review.csv` есть 3 повторяющихся `id` и 3 повторяющихся естественных ключа
   `name + city + address + phone`.

4. В `review.csv` встречаются значения, которые нельзя загрузить без нормализации:
   `rating = N/A` в 1 строке, рейтинг с десятичной запятой `"4,5"` в 1 строке.

5. В `review.csv` есть пропуски контактов:
   58 пустых `site` и 20 пустых `phone`.

## Как обнаружено

Скрипт `scripts/analyze-data.mjs` читает все `page_*.json`, затем `review.csv`, нормализует значения теми же функциями, что и импортёры, и сравнивает:

- количество строк и уникальных `id`;
- пересечение `id` между JSON и CSV;
- дубли внутри CSV;
- естественный ключ `name + city + address + phone`;
- значения рейтинга и пустые контактные поля.

При загрузке `review.csv` скрипт `scripts/load-review.mjs` дополнительно пишет найденные проблемы в таблицу `import_anomalies`.
